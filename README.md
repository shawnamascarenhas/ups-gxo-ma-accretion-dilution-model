# UPS-GXO M&A Accretion/Dilution Model

This project presents a hypothetical acquisition of GXO Logistics by
United Parcel Service. It was developed as part of my MSc Finance
application portfolio.

The model includes:

- Standalone buyer and target forecasts
- Transaction valuation
- Sources and uses
- Acquisition financing and debt repayment
- Purchase accounting
- Pro forma income statement
- EPS accretion/dilution
- Synergy breakeven analysis
- Credit and return metrics
- Base, upside and downside scenarios
- Transaction sensitivities
- Executive summary and investment memo

## Headline conclusion

The base case is dilutive in FY2026 and FY2027 before becoming 2.0%
accretive in FY2028. However, incremental ROIC remains below the
illustrative WACC through FY2028, supporting a conditional rather than
unqualified transaction recommendation.

## Disclaimer

This is an independent educational exercise based on a hypothetical
transaction. It is not investment advice, company guidance, or an
indication that either company is considering such a transaction.
